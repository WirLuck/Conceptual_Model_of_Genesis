# 08 — 2D Moving Visual Model Specification / Spesifikasi Model Visual Bergerak 2D

## Chosen representation / Representasi yang dipilih

### 🇮🇩
Versi 2D digunakan sebagai representasi visual resmi sementara karena paling dekat dengan model konseptual yang telah disepakati. Percobaan interpretasi 3D sebelumnya **ditinggalkan** karena menambahkan bahasa visual baru (particle field/network) yang tidak terdapat pada konsep yang dipilih.

### 🇬🇧
The 2D version is the current official working visual representation because it remains closest to the agreed conceptual model. The previous 3D reinterpretation is **discarded** because it introduced visual language (particle fields/networks) that was not part of the selected concept.

## Visual ontology / Ontologi visual

```text
PRIMORDIAL SUBSTANCE — P
(no defined external edge)
████████████████████████████████████████
███████████▓▓▒▒  Ω  ▒▒▓▓███████████████
████████████████████████████████████████
```

The important distinction is:

\[
\Omega \subset P
\]

while

\[
\partial P \; \text{is not defined in the model.}
\]

The visible boundary of \(\Omega\) is therefore **not** a boundary of P.

## Four visual stages / Empat tahap visual

1. **Reframing nothingness** — conceptual stage; P is never absent.
2. **P + Cₚ** — Primordial Substance with primordial consciousness as an intrinsic aspect.
3. **Differentiation / Ω emergence** — a created/emergent differentiated domain develops internally.
4. **Spacetime/cosmic development** — spatial-temporal and physical structures develop within Ω.

## Critical rules / Aturan kritis

- The entire canvas represents P; the screen edge is only a **display edge**.
- The background is not “nothingness”.
- Cₚ is not a glowing object inside P; it is represented as a property/state of P as a whole.
- The centered Ω is a display convention, not evidence for a literal center of creation.
- The sequence \(\Sigma_1\to\Sigma_2\to\Sigma_3\to\Sigma_4\) is model ordering, not automatically ordinary physical time.
- No visual element may be added merely for aesthetic effect if it changes the ontology being communicated.
