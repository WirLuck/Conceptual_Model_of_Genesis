# 08 — Spesifikasi Model Visual / Visual Model Specification

## Status / Status

🇮🇩 Dokumen ini mendefinisikan representasi visual konseptual PSESH yang digunakan saat ini. Model visual ini **bukan simulasi fisika tervalidasi** dan tidak boleh diperlakukan sebagai hasil dari hukum dinamika yang telah ditemukan.

🇬🇧 This document defines the current conceptual visual representation of PSESH. The visual model is **not a validated physical simulation** and must not be treated as an output of a discovered dynamical law.

## Representasi minimum / Minimal representation

```text
PRIMORDIAL SUBSTANCE
████████████████████████████

       differentiation
██████████▓▓▒▒░░▒▒▓▓████████

       structured state
██████▓▒○──○──○▒▓███████████

       cosmic development
████▓▒○──☉──✦──◎──●──✧▒▓████
```

## 🇮🇩 Interpretasi

1. **Primordial Substance** — keseluruhan representasi berada dalam konteks P. Tepi layar bukan batas ontologis P.
2. **Differentiation** — `░▒▓` menggambarkan diferensiasi secara konseptual; simbol tersebut bukan ukuran kepadatan materi kecuali kelak ada derivasi yang membenarkannya.
3. **Structured state** — `○──○──○` merepresentasikan struktur/relasi. Garis pada tahap ini tidak harus berarti jarak fisik literal.
4. **Cosmic development** — garis kemudian digunakan sebagai representasi ruang emergen yang menjadi domain bagi struktur/benda kosmik.
5. Bagian `█▓▒...▒▓█` tetap merupakan konteks P dan bukan ruang kosong di luar P.
6. `C_P` dan `W_P` diperlakukan sebagai aspek primordial P tetapi tidak harus digambar sebagai objek terpisah.
7. Urutan gambar adalah urutan penjelasan model dan tidak otomatis berarti waktu fisik sudah ada pada seluruh tahap.
8. Waktu tetap merupakan masalah terbuka; diagram ini secara khusus menggunakan garis untuk merepresentasikan **ruang** pada tahap kosmik.

## 🇬🇧 Interpretation

1. **Primordial Substance** — the entire representation remains within the context of P. The screen edge is not an ontological boundary of P.
2. **Differentiation** — `░▒▓` conceptually depicts differentiation; these symbols are not a measure of matter density unless a future derivation justifies such an interpretation.
3. **Structured state** — `○──○──○` represents structure/relations. At this stage the line need not mean literal physical distance.
4. **Cosmic development** — the line is subsequently used to represent emergent space that becomes the domain for cosmic structures/objects.
5. The surrounding `█▓▒...▒▓█` remains the P context and is not empty space outside P.
6. `C_P` and `W_P` are treated as primordial aspects of P but need not be drawn as separate objects.
7. The sequence is an explanatory ordering of the model and does not automatically imply that physical time exists throughout all stages.
8. Time remains an open problem; this diagram specifically uses the line to represent **space** at the cosmic stage.

## Aturan visual / Visual rules

🇮🇩 Visualisasi baru tidak boleh menambahkan particle field, network, batas luar, pusat kosmos, atau struktur lain sebagai bagian PSESH hanya untuk alasan estetika. Jika visual baru memerlukan asumsi tambahan, asumsi itu harus dinyatakan secara eksplisit.

🇬🇧 New visualizations must not introduce particle fields, networks, an external boundary, a cosmic center, or other structures as part of PSESH merely for aesthetic reasons. If a new visual requires additional assumptions, those assumptions must be explicitly stated.
