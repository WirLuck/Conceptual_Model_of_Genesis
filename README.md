# Primordial Substance Research / Riset Primordial Substance

> **Version:** v0.3 — 2D Visual Integration / Integrasi Visual 2D  
> **Status:** Independent conceptual research / working hypothesis — **not an established physical theory and not a scientific proof of God.**  
> **Bahasa / Languages:** Indonesia + English.

## 🇮🇩 Ringkasan

Repositori ini menyusun secara bertahap sebuah kerangka hipotesis tentang **ketiadaan, Primordial Substance, kesadaran primordial, penciptaan, diferensiasi, kemunculan ruang-waktu, perkembangan alam semesta, dan kesadaran individual**.

Kerangka kerja saat ini menggunakan nama sementara **Primordial Substance–Emergent Spacetime Hypothesis (PSESH)**.

PSESH v0.2 mengoreksi satu hal penting dari v0.1: model ini **tidak sekadar “tidak mengasumsikan” ketiadaan absolut**. Ia mengajukan proposisi bahwa **ketiadaan absolut tidak pernah merupakan keadaan ontologis yang nyata**. Istilah “ketiadaan” diperlakukan sebagai **ketiadaan relatif terhadap sesuatu dalam suatu kerangka/perspektif**.

PSESH juga menempatkan **kesadaran primordial** sebagai sifat/aspek yang sudah dimiliki Primordial Substance pada level fondasional, bukan sebagai sesuatu yang baru muncul hanya setelah materi biologis berkembang.

## 🇬🇧 Summary

This repository progressively organizes a hypothesis concerning **nothingness, Primordial Substance, primordial consciousness, creation, differentiation, the emergence of spacetime, cosmic development, and individual consciousness**.

The current provisional name is the **Primordial Substance–Emergent Spacetime Hypothesis (PSESH)**.

PSESH v0.2 corrects an important point from v0.1: the model does **not merely refrain from assuming absolute nothingness**. It proposes that **absolute nothingness has never been an instantiated ontological state**. “Nothingness” is instead treated as **relative absence with respect to something within a frame or perspective**.

The model also places **primordial consciousness** at the foundational level of Primordial Substance rather than treating consciousness as something that appears only after biological matter becomes complex.

## Core model / Model inti

```text
STAGE 1 — Ontological reframing (logical, not temporal)
Nothingness = relative absence, not absolute non-being
N(X|F) = absence of X within frame F
Absolute nothingness is proposed to never be instantiated
                 │
                 ▼
STAGE 2 — Primordial Substance (P)
P exists fundamentally; no temporal moment is asserted in which P is absent
P includes primordial consciousness C_P as a foundational aspect
P is not located inside pre-existing ordinary space or time
                 │
                 ▼
STAGE 3 — Differentiation / creation
P undergoes or grounds differentiation through an unknown generative law G
relations / distinguishability / spatiality / temporal order emerge
physical energy and fields become meaningful in the emergent regime
                 │
                 ▼
STAGE 4 — Cosmic development
spacetime → fields/matter → structures → life → individual consciousness (?)
physical and historical development occurs within this emergent domain
```

> **Important:** the stage numbers are an explanatory order, not necessarily a clock-time sequence. If time itself is emergent, Stages 1–2 cannot be interpreted as ordinary moments “before” time.

## Boundaryless principle / Prinsip tanpa batas luar

The visual model must **not** imply an empty exterior surrounding Primordial Substance. PSESH currently proposes that Primordial Substance is not bounded by an external spatial edge because ordinary space is an emergent property of creation. Likewise, ordinary temporal beginning/end concepts belong to the emergent temporal domain.

Any later boundary, extent, horizon, beginning, or ending of physical spacetime—if such a feature exists in the formal model—is **a structure within emergence**, not an external edge of Primordial Substance.

## Research discipline / Disiplin penelitian

```text
Intuition → definition → formal law → computation → prediction → test → revision
```

not / bukan:

```text
Intuition → draw the desired result → call it evidence
```

A **2D moving conceptual visualization** is now included for communication and review. It is not yet the authoritative computational simulator. The later simulator must still be generated from explicit dynamical laws rather than manually forced to resemble the researcher's intuition.
